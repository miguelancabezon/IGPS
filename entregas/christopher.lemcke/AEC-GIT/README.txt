Creé un fork del repositorio original en mi cuenta de GitHub.

Cloné mi fork en mi ordenador utilizando Git desde la terminal.

Dentro del repositorio local accedí a la carpeta "entregas".

Dentro de "entregas" creé una carpeta con mi nombre y, dentro de ella, una nueva carpeta llamada "AEC-GIT".

Dentro de "AEC-GIT" creé el archivo README.txt.

Desde la raíz del repositorio añadí el nuevo archivo al area de staging utilizando "git add". 

Cree un commit con el mensaje "Docs: Nuevo archivo". 

Subi los cambios a la rama main de mi fork con "git push origin main". 

Desde la rama main creé una nueva rama llamada "docs/modificaciones" y cambié a ella.

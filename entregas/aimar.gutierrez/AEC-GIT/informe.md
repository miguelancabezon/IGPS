# Informe AEC-GIT

Alumno: Aimar Gutierrez

## Introduccion

En esta actividad he practicado el flujo basico de Git y GitHub: fork, clonado, ramas, commits y Pull Request.

## Pasos 1 a 3: fork, clonado y primer commit

Hice un fork del repositorio del docente y lo clone con git clone. Despues cree las carpetas entregas\aimar.gutierrez\AEC-GIT con mkdir. En cmd de Windows mkdir no admite la opcion -p, asi que lo ejecute sin ella.

Cree el archivo informe.md, lo anadi con git add, hice el commit docs: nuevo archivo y lo subi con git push origin main.

## Paso 4: rama de trabajo

Cree la rama docs/modificaciones con git checkout -b y edite este archivo haciendo varios commits descriptivos.

## Conclusiones

He aprendido a hacer un fork, clonar un repositorio, trabajar con ramas, hacer commits y subir cambios a GitHub.

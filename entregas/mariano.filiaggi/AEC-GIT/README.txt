AEC-GIT - Actividad de Evaluación Continua

Alumno: Mariano Filiaggi

INTRODUCCIÓN

En esta actividad se practica el flujo básico de trabajo con Git y GitHub.

El objetivo es aprender a trabajar con repositorios, ramas, commits y Pull Requests.

PROCESO REALIZADO HASTA AHORA

1. Realicé un Fork del repositorio original proporcionado por el docente.
2. Cloné mi Fork en el ordenador mediante git clone.
3. Creé la carpeta entregas.
4. Dentro de entregas creé la carpeta mariano.filiaggi.
5. Dentro de ella creé la carpeta AEC-GIT.
6. Creé el archivo README.txt vacío.
7. Añadí el archivo al área de staging mediante git add.
8. Realicé el primer commit con el mensaje "docs: nuevo archivo".
9. Subí el commit a mi repositorio remoto mediante git push origin main.
10. Creé la rama docs/modificaciones para continuar trabajando.
